# Резервные копии

«Резервные копии» доступны в боковой панели, настройках и сведениях об установленной программе.
Выберите программу → «Экспортировать настройки». История показывает дату, время, размер ZIP и место хранения.
Все даты отображаются в местном времени Windows. Старые копии не перезаписываются и автоматически не удаляются.

Каждый экспорт сохраняется в `%LOCALAPPDATA%/ThodHUB/Backups`, затем отправляется в приватный GitHub,
если он подключён. При ошибке загрузки локальный ZIP остаётся, а приложение сообщает, что облачная копия не создана.
Перед деинсталляцией предложение сделать копию включено по умолчанию. При ошибке копирования удаление не продолжается.

Приватный репозиторий: `ThodProd/ThodHUB-Backups`, release `thodhub-backups-v1`, отдельный asset на каждую копию.
Другие пользователи могут указать собственный приватный репозиторий с хотя бы одним коммитом.
Требуется GitHub-вход: сохранённая авторизация GitHub CLI либо fine-grained token с Contents: Read and write
только к этому репозиторию. Токен защищён Windows DPAPI, хранится отдельно в Secrets и никогда не входит в ZIP.
После переустановки Windows подключите GitHub заново. Публичные репозитории для конфигов хаб отвергает.
ZIP в приватном GitHub не шифруется дополнительно: доступ регулируется правами репозитория.

Восстановление: выбрать дату → «Восстановить» → подтвердить. Программу нужно закрыть.
Перед заменой текущих данных автоматически создаётся ещё одна **локальная** копия.
Копии другой программы и архивы с небезопасными путями не принимаются.
Можно восстановить данные до установки самой программы. Для этого выберите её копию из истории.

Копируются файлы Data/<id>, кроме верхнеуровневых cache, logs, tmp, temp, runtime.
Не копируются исполняемые пакеты, токен GitHub и содержимое ссылок/junction. Предел: 256 МБ ZIP, 1 ГБ исходных данных,
20 000 файлов. Хаб сообщает об ошибке вместо незаметного усечения копии.
Отдельная запись «ThodHUB · оформление и порядок» сохраняет тему, настройку проверок и порядок иконок;
восстановление не подменяет список реально установленных программ.

Агентам: храните конфиги/базы только в THODHUB_DATA_DIR. Кэш и скачиваемые модели размещайте в cache.
Не переносите секреты в исходники или публичный каталог. Для корректного снимка базы приложение должно быть закрыто.
