# Дизайн и быстродействие

Поверхность: ежедневное настольное приложение Windows, минимальный размер 820×560.
Контрольные размеры web-области: 1200×760 и 840×560.
Основное действие: открыть установленную утилиту; второе — добавить из каталога.
Боковая панель 224 px, библиотека с умеренными карточками, модальный каталог,
отдельные настройки. Описание не вытесняет элементы управления.

Направление: спокойное, компактное, нейтральное. Светлая тема — тёплый белый и
серые поверхности; тёмная — графит. Один синий акцент для действий и выбора.
Шрифт Segoe UI Variable/Segoe UI использует системную отрисовку Windows;
Inter рассматривается как переносимый вариант, а не системная установка.
Иконки — простые SVG, картинки карточек представляют назначение конкретной утилиты.
Без декоративных больших заголовков, градиентных баннеров и фиктивной статистики.

Референсы:
- Apple Sidebars: https://developer.apple.com/design/human-interface-guidelines/sidebars
  — настраиваемый порядок, знакомые символы и краткие названия.
- Apple Designing for macOS: https://developer.apple.com/design/human-interface-guidelines/designing-for-macos
  — управляемая плотность, изменение размера окна и клавиатура.
- Mobbin: https://mobbin.com — изучена открытая страница библиотеки;
  закрытые экраны приложений не просмотрены и не выдаются за источник макета.
- Inter: https://rsms.me/inter — рассмотрен открытый интерфейсный шрифт.

Состояния: загрузка сохраняет каркас и показывает прогресс; пустая библиотека ведёт
в каталог; ошибка даёт повторить; частично обновлённый каталог сохраняет доступные
данные с предупреждением; успех установки ведёт в программу; права модуля объясняются
перед первой установкой. Подготовка интеграции видна явно, без ложной кнопки установки.

Производительность: оболочка не ждёт сети для показа кеша, максимум 4 параллельных
проверки релизов, загрузки асинхронные, проверка и распаковка пакетов вне UI-потока,
исполняемая часть каждой утилиты в отдельном процессе. Переключение не пересоздаёт
оболочку. Замеры запуска, памяти и переключений выполняются на собранном приложении;
до измерения численные обещания не даются.

Проверки: модальный фокус, Escape, видимый focus, перетаскивание и клавиатурные
кнопки порядка, длинные подписи, обе темы, reduced-motion и указанные размеры.
