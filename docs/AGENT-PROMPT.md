Отдельное окно: mode=standalone, готовый exe со всеми runtime, launch.executable.
Внутри хаба: mode=embedded, локальный HTML/CSS/JS + sdk/thodhub.js, отдельный worker для тяжёлой работы.
Входы/выходы, разрешения, JSON-RPC, переменные окружения и cleanup описаны в MODULE-CONTRACT.md.
Конфиги и базы — только THODHUB_DATA_DIR; cache/logs/tmp/runtime отдельно от постоянных данных.
Зависимости включай в пакет либо сделай понятный первый запуск с установкой, прогрессом, журналом и официальной ссылкой.

При каждой правке обновляй версию проекта и manifest, собирай новый ZIP, пересчитывай SHA-256 и size,
публикуй стабильный hub-vX.Y.Z с ZIP и thodhub-release.json. Старые assets не заменяй.
Для новой программы добавь запись в main каталога. Для новой версии достаточно release;
при изменении описания/шапки/режима обнови также каталог, сохранив чужие записи.
JSON — UTF-8 без BOM, пути через /, manifest в корне ZIP. Следуй RELEASE-CHECKLIST.md.
