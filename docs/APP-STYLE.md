# Стиль программ ThodHUB

Интерфейс на русском. Короткие названия действий: «Выбрать папку», «Конвертировать», «Сохранить».
Показывайте рабочую задачу сразу, без приветственного лендинга, маркетинговых баннеров и декоративной статистики.

## Общие правила
- Шрифт: Segoe UI Variable / Segoe UI, системный fallback sans-serif. Основной текст 14 px, подписи 12–13, заголовок страницы 24–28, разделы 16–18. Не устанавливайте шрифт в Windows.
- Отступы кратны 4/8: между контролами 8–12, между разделами 20–28, край страницы 24–32 px.
- Скругления: поля/кнопки 8 px, панели 12–14. Тонкая рамка 1 px, тени только у модальных окон.
- Светлая тема: фон #FFFFFF, боковая #F5F5F7, поверхность #F7F8FA, текст #24262B, подписи #767B85, линия #E8E9ED, акцент #3676E8.
- Тёмная: фон #1C1D20, боковая #17181B, поверхность #25262A, текст #ECEDF0, подписи #989CA5, линия #303136, акцент #81AAFF.
- Красная кнопка только для необратимого действия: #B92F3A, белый текст. Для опасной операции показывайте цель и подтверждение, без автоматического запуска.
- Иконки SVG 18–20 px, обводка 1.5–1.75, один понятный набор. Не заменяйте интерфейс случайными emoji.
- Один главный синий action на рабочий блок; вторичные действия спокойные. Не размещайте всё в одинаковых карточках.
- Минимальная область встроенного UI 580×440; отдельного окна около 720×560. Панели должны прокручиваться, важные кнопки оставаться доступны.
- Клавиатура: Tab, явный focus, Enter для подтверждения обычных форм, Escape закрывает диалог. Не используйте Enter по умолчанию для уничтожения данных.
- Движение 120–180 мс; учитывайте prefers-reduced-motion. Прогресс должен отражать реальную операцию, а не бесконечную имитацию.
- При ошибке: понятная причина, кнопка повторения, раскрываемый технический журнал без секретов. Нельзя показывать успех при неполном результате.

Встроенный интерфейс получает `?theme=light` или `?theme=dark`; подстройте все поверхности, поля и текст.
Тяжёлая работа выполняется отдельным процессом. Длинные задания возвращают jobId сразу, интерфейс опрашивает статус/прогресс и поддерживает отмену.

## Карточка каталога и шапка
В JSON задайте `kind` — короткое русское назначение: «Конвертер», «Просмотр изображений», «VPN», «Аудиомикшер».
`description` — 1–2 конкретных предложения на русском, до 160 символов, без повторения имени и рекламных лозунгов.
Пример: `"kind":"Конвертер", "description":"Преобразование фото, видео и звука. Сжатие, обрезка и удаление фона без отправки файлов в сеть."`.

Шапка — **горизонтальная иллюстрация**, а не квадратная иконка:
- SVG с `viewBox="0 0 800 420"`, либо WebP/PNG 1600×840; <=200 КБ.
- Спокойный светлый фон из палитры программы, одна центральная композиция, крупный читаемый силуэт.
- Покажите назначение: кадры и звук для конвертера, фотографию и лупу для просмотрщика, документ для резюме.
- Без текста, мелких подписей, чужих логотипов, синего/фиолетового неона и обрезанного квадратного app-icon.
- SVG полностью самостоятельный: без scripts, внешних ссылок, шрифтов и растровых ресурсов по URL.
- Значимые элементы внутри центральных 70% ширины и 75% высоты. Карточка использует object-fit:cover.
- Запишите в `ThodHUB-Registry/assets/<id>.svg`. `artworkUrl` — raw.githubusercontent.com URL.
- При изменении изображения добавьте версию к URL `?v=2`, чтобы сбросить кэш.

Смотрите реальные примеры `registry/assets/thodmedia.svg` и `thodview.svg`. Имя, назначение, описание,
размер скачивания и версия рисуются самим хабом **под** иллюстрацией. Не дублируйте их внутри SVG.
Размер пакета показывайте обычным приглушённым текстом рядом с версией и кнопкой установки.
Внутри кнопки должно быть только действие «Установить» / «Обновить», без размера и версии.

## Иконка обязательна
У каждой программы должна быть собственная узнаваемая иконка, отдельная от горизонтальной шапки.
- Исходник: самостоятельный квадратный SVG, без текста и мелких деталей; силуэт читается при 16–32 px.
- Для Windows подготовьте настоящий многоразмерный ICO: 16, 24, 32, 48, 64, 128 и 256 px.
- Встройте ICO в EXE (WPF/.NET: `ApplicationIcon`, PyInstaller: `--icon`, Electron: `win.icon`).
- Используйте ту же иконку в окне, панели задач и ярлыке. Не оставляйте стандартную иконку WPF, Python или Electron.
- В каталоге и боковой панели используйте квадратную иконку приложения; `artworkUrl` предназначен только для шапки.
- Храните SVG/ICO в репозитории, включайте необходимые файлы в пакет. Для встроенной утилиты обязательна иконка каталога, даже если у worker нет видимого окна.
- При исправлении иконки выпускайте новую версию пакета; уже опубликованные ZIP не заменяйте.

## Обновления и окна
Основная кнопка установленной программы всегда «Открыть». Обновление — отдельная стрелка на обложке и возле программы слева. В разделе обновлений обязательны версия до/после, изменения, размер и кнопка «Обновить» с реальным прогрессом. Размер обычным текстом справа непосредственно перед кнопкой установки. В окне один крестик сверху, Escape и закрытие по фону; нижние «Закрыть» не дублировать. Управление отделять от установки; удаление называть «Удалить программу». В редакторе сверху справа слои, ниже только параметры выбранного инструмента. Горячие клавиши по KeyboardEvent.code работают и в русской раскладке.

Карточка библиотеки целиком открывает полные сведения. Описание в компактной карточке прокручивается колесом при наведении; не обрезайте его без возможности прочитать. Удаление, экспорт/импорт базы и настроек, история копий и ремонт интеграции должны быть доступны в полной карточке. Ярлык на рабочем столе называется только именем проекта, без префикса хаба.
