# ThodHUB

Личная библиотека Windows-программ. Каталог — [ThodHUB-Registry](https://github.com/ThodProd/ThodHUB-Registry), пакеты — GitHub Releases.

## Запуск
Скачайте ZIP в [выпусках](https://github.com/ThodProd/ThodHUB/releases/latest), распакуйте **всю папку** в постоянное место и запустите `ThodHUB.exe`.
Windows 10/11 x64, Microsoft Edge WebView2 Runtime (обычно уже установлен).
Python, Node и .NET SDK пользователю не нужны. Авторизация GitHub не требуется.

Нажмите «+», выберите программу и установите её. После переустановки Windows достаточно снова скачать хаб.

## Возможности
- Каталог с картинками, версиями и изменениями; обновления устанавливаются по кнопке.
- Отдельная кнопка снизу слева сообщает о новой версии самого хаба; обновления программ — зелёной стрелкой на панели слева.
- Правый клик по установленной программе открывает «Открыть», «Сведения и управление» и «Удалить». Тяжёлые действия сгруппированы в карточке программы.
- Встроенные утилиты с отдельным рабочим процессом и полноэкранным режимом.
- Самостоятельные программы в отдельных окнах и ярлыки на рабочем столе.
- Реальное удаление установленных файлов и ярлыка; удаление данных — отдельный выбор.
- Откат версии, проверка SHA-256 пакетов, отмена загрузки.
- Перестановка программ мышью или кнопками, светлая/тёмная/системная тема.
- Установленные программы и кэш каталога доступны без сети.

Данные: `%LOCALAPPDATA%\ThodHUB\Data\<id>`, файлы программ: `Apps/<id>/<version>`, список: `hub.json`.
В разделе «Резервные копии» можно сохранить настройки локально и в приватный GitHub-репозиторий.
Каждая копия хранится отдельно с датой и размером; для восстановления выберите нужную дату.
Подключение GitHub нужно только для облачных копий, каталог работает без входа. Подробности: [BACKUPS.md](docs/BACKUPS.md).
Перед обновлением/удалением программу нужно закрыть, включая значок в трее.
Сам хаб обновляется заменой его распакованной папки после закрытия; данные находятся отдельно.
После переноса хаба пересоздайте ярлыки кнопкой в карточке программы.

## Разработка и ограничения
Windows, .NET SDK 10. `dotnet run --project tests/ThodHub.Tests`, `dotnet build src/ThodHub`, `./scripts/build-hub.ps1`.
[Проверки](docs/VALIDATION.md). В 0.1.0 автозапуск Mixer/Monitor в сборках хаба отключён;
самостоятельные исходные сборки его сохраняют. VPN требует рабочего профиля, Monitor — прав администратора.
Сборки без Authenticode-подписи. Manifest-разрешения ограничивают веб-мост, но exe являются доверенными локальными программами, не песочницей.
