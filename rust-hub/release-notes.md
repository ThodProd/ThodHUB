В правом нижнем углу обложек в библиотеке и каталоге появился значок основного языка программы.
Хаб читает язык из манифеста или каталога. Для остальных программ он может определить язык по статистике исходников GitHub и сохранить результат для работы без сети.
Шесть точек для перетаскивания установленных программ выровнены по центру строки в боковом меню.
